# Zeta Conversation Exporter

사용자가 직접 연 Zeta 채팅방 하나의 전체 대화를 JSON과 Markdown으로 함께 저장한다.

## 턴 기준

- 사용자가 전송한 채팅 한 번은 1턴이다.
- Zeta AI가 생성한 응답 전체는 1턴이다.
- AI 응답 안에 나레이션과 여러 캐릭터 대사가 함께 있어도 모두 같은 1턴에 포함한다.
- 팝업, JSON, Markdown 모두 이 기준의 `turn`만 사용한다.

## 사용 흐름

1. 내보낼 `https://zeta-ai.io/ko/rooms/...` 채팅방에 들어간다.
2. 익스텐션을 열고 **이 채팅방 Export**를 누른다.
3. 익스텐션이 최신 메시지부터 최초 메시지까지 이동해 과거 대화를 모두 로드한 뒤, 각 메시지 행이 화면에 배치된 세로 위치를 기준으로 시간순 정렬한다. 완료 후 원래 스크롤 위치로 돌아온다.
4. 전체 턴 수를 확인한다.
5. 저장을 확인하면 JSON과 Markdown 두 파일이 함께 다운로드된다.
6. 원하면 **다음부터 저장 전 확인 생략**을 체크한다.

같은 방을 다시 열면 마지막 전체 스캔에서 확인한 턴 수를 즉시 보여준다. 실제 export 전에는 전체 대화를 다시 읽어 최신 턴 수를 확정한다.

## JSON 형식

최소 형식으로 제목, export 시각, 전체 턴 수, 턴 목록만 기록한다.

- 최상위 필드는 `title`, `exported_at`, `turn_count`, `turns`뿐이다.
- `turns[]`의 각 항목은 `turn`, `role`, `speaker`, `text`만 담는다.
- `Turn 1`은 채팅방에서 가장 오래된 대화이고 마지막 turn은 가장 최신 대화다.
- `role`은 `user` 또는 `character`다.
- 한 AI 턴에 여러 화자가 있으면 `speaker`에 화자들을 함께 기록하고, `text` 안에는 `[나레이션]`, `[캐릭터명]` 표기를 붙여 순서를 보존한다.
- `<em>` 서술은 `*서술*` 형태로 보존한다.

Zeta의 room ID와 메시지 key는 전체 스크롤 중 중복 수집을 막고 파일명을 만드는 내부 용도로만 사용하며, 다운로드 파일에는 넣지 않는다.

Markdown도 같은 `Turn N · 사용자/AI` 순서로 출력한다.

## 설치

1. `chrome://extensions`에서 개발자 모드를 켠다.
2. 이 폴더를 **압축해제된 확장 프로그램**으로 로드한다.
3. 코드를 갱신했다면 익스텐션 카드의 새로고침 버튼과 Zeta 채팅방 새로고침을 차례로 누른다.

## 제약

- Zeta는 가상 목록을 사용하므로 정확한 전체 턴 수는 전체 스캔 후에만 알 수 있다.
- 현재 채팅 DOM은 `frame.pingpong.ai` iframe 안에 있으므로 익스텐션은 해당 프레임에도 content script를 주입한다.
- 스캔 중 대화창이 자동으로 움직인다.
- 삭제된 메시지, 선택하지 않은 응답 후보, DOM에 제공되지 않는 메타데이터는 포함되지 않는다.
